# VibeCode Control

Управляющий контур контролируемой AI-разработки: от проверки и принятия проекта до настройки фоновых агентов, quality gates, review и выпуска по проверяемым доказательствам.

Скилл умеет:

- подключать новый или действующий репозиторий через безопасные `init` и `adopt`;
- хранить исполняемый граф узлов, ролей, моделей, effort, прав и переходов;
- назначать каждому узлу проверенный скилл либо обоснованный `zero-skill`;
- доставлять закреплённые скиллы фоновым Claude и Codex;
- проверять Git, GitHub, CI, тесты, документацию, безопасность и evidence package;
- диагностировать и исправлять схему через `doctor` и `scheme check`;
- планировать изменения с dry-run, SHA-256, проверкой drift и rollback.

Основной файл скилла — [SKILL.md](SKILL.md). Результат сравнения с похожими решениями опубликован в [аудите skills.sh](docs/skills-sh-audit-2026-08-02.md).

Публичное имя скилла — `vibecode-control`. Внутренние совместимые имена CLI и проектных файлов пока сохранены: `devflow`, `.agent-flow`, `devflow-node`.

Текущая версия: `0.1.0`.
